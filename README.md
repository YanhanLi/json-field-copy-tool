# JSON 字段复制工具

这是一个零依赖本地小工具，用来把结构化 JSON 数据拆成可直接复制的单独字段，适合表单录入、内容回填和分字段复制场景。

## 现在能做什么

- 自动扫描当前工作目录下文件名包含 `json` 的结构化数据文件
- 按表单顺序拆分字段：`评分点 -> 类型 -> 得分 -> 来源 -> 引用 -> 说明`
- 支持复制单个字段
- 支持 `复制并前进`，一路顺着填写同一条记录
- 支持切换到上一条 / 下一条记录
- 支持复制整条字段包
- 支持按关键词筛选

## 最推荐的用法

1. 选择一个 JSON 文件
2. 点击左侧某条记录的 `打开字段填写`
3. 在右侧按顺序填表
4. 每填完一个字段，就点一次 `复制并前进`
5. 填完整条后，继续下一条记录

## 快捷键

- `Enter`：复制当前字段并前进
- `↑`：回到上一个字段
- `↓`：前进到下一个字段

## 适用文件

默认会扫描当前目录及子目录下的 `.json` 文件；如果是结构化数组数据，就可以直接用于字段拆分和复制。

## 批量自动填表

如果目标网页是分条展开的表单，可以直接使用：

`browser/form-autofill.userscript.js`

用法：

1. 安装 Tampermonkey
2. 新建脚本并粘贴 `browser/form-autofill.userscript.js`
3. 打开目标表单页面
4. 把 `rubrics_all.json` 粘到页面右下角浮层
5. 点击 `展开并填充`

这份脚本会尝试：

- 按 `NO. 1 / NO. 2 / NO. 3 ...` 找到页面卡片
- 自动展开折叠项
- 按标签文本填写 `评分点 / 类型 / 得分 / 来源 / 引用 / 说明`

## 说明

- 不依赖第三方包
- 不会改动原始 JSON
- 如果浏览器不允许直接写剪贴板，字段内容仍会显示在页面里，可以手动复制
